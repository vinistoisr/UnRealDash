# Reports

Measured gate evidence, device facts and the Stage 0 feasibility report belong
here (PLAN.md 0.8, 0.9 and 7.1). Label assumptions and targets separately from
measurements. Packaged builds, raw large captures and source code do not belong here.

## Reports here

- `device-pixel10pro.md`: the desk device's facts, and what they change about PLAN's assumptions.
- `2026-09-17-smoke-spike.md`: PLAN 4.0, what was proved, what was not, and the findings.
- `logs/`: evidence from device runs, including logcat for any launch failure.
